# 🧮 Scientific Calculator using React

A modern and responsive **Scientific Calculator** built using **React.js and Vite**.  
The application provides basic arithmetic operations along with advanced scientific, trigonometric, logarithmic, and mathematical functions.

## 🚀 Live Demo

🔗 **Live Website:**https://scientific-calaculator-using-react-five.vercel.app/




## 📌 Features

### Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Plus/Minus (±)
- Decimal numbers
- Parentheses

### Scientific Functions
- Square (x²)
- Cube (x³)
- Power (xʸ)
- Square Root (√)
- Cube Root (∛)
- Reciprocal (1/x)
- Absolute value
- Floor
- Ceiling
- Factorial (!)

### Trigonometric Functions
- sin
- cos
- tan
- asin
- acos
- atan

### Hyperbolic Functions
- sinh
- cosh
- tanh
- asinh
- acosh
- atanh

### Logarithmic & Exponential Functions
- log
- ln
- 10ˣ
- eˣ

### Angle Modes
- DEG – Degree
- RAD – Radian
- GRAD – Gradian

### Additional Features
- π (Pi)
- e (Euler's number)
- Modulus
- Calculation history
- Copy result
- Backspace
- Clear / All Clear
- Keyboard support
- Light/Dark theme
- Responsive design
- History stored using Local Storage
